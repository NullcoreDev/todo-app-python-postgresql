# TODO App

Консольное приложение для управления задачами с использованием Python и PostgreSQL.

Проект создан в учебных целях для практики Python, SQL, PostgreSQL и Git.

## Возможности

Приложение позволяет:

- добавлять задачи
- просматривать список задач
- находить задачу по ID
- отмечать задачу как выполненную
- редактировать название задачи
- удалять задачи
- отображать дату и время создания задачи
- хранить данные в PostgreSQL

Технологии

- Python
- PostgreSQL
- psycopg
- python-dotenv
- SQL
- Git
- GitHub

## Как работает приложение

После запуска появляется меню:

--------TODO--------
1. Добавить задачу
2. Показать задачи
3. Выполнить задачу
4. Удалить задачу
5. Редактировать задачу
6. Найти задачу
7. Выйти

Все операции с задачами выполняются через PostgreSQL.

## Установка

1. Клонирование репозитория

git clone https://github.com/NullcoreDev/todo-app-python-postgresql.git

Перейдите в папку проекта:

cd todo-app-python-postgresql

2. Установка зависимостей

Установите необходимые библиотеки:

pip install psycopg[binary] python-dotenv

3. Настройка PostgreSQL

Создайте базу данных todo.

После этого создайте таблицу:

CREATE TABLE tasks (
    id SERIAL PRIMARY KEY,
    title VARCHAR(255) NOT NULL,
    completed BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

4. Настройка переменных окружения

В корне проекта создайте файл .env:

DB_HOST=localhost
DB_PORT=5432
DB_NAME=todo
DB_USER=postgres
DB_PASSWORD=ваш_пароль

Файл .env не должен загружаться в GitHub.

5. Запуск

Запустите приложение:

python task.py

## Обработка ошибок

Приложение обрабатывает некорректный ввод пользователя.

Например, если вместо ID введено не число:

Введите id задачи: abc

Нужно ввести число!

Также проверяется существование задачи перед её изменением, удалением или поиском.

## Безопасность

Конфиденциальные данные подключения к PostgreSQL хранятся в .env.

Файл .env добавлен в .gitignore и не публикуется в GitHub.

SQL-запросы с пользовательскими значениями используют параметры %s, а не формирование SQL через f-строки.
